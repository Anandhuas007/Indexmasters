LEARN INDEX NUMBERS

Understand Index Numbers

Learn the concepts, formulas and methods behind price index numbers step by step.

01 · BASICS

What are Index Numbers?

An index number is a statistical measure used to show changes in the value of a variable or group of variables over time.

In economics and business, index numbers are commonly used to measure changes in prices, quantities and values between a base period and a current period.

02 · PURPOSE

Why are Index Numbers Used?

📈 Measure Change

They help measure how prices or quantities have changed between different periods.

💰 Compare Prices

Price index numbers can be used to compare price levels between a base period and a current period.

📊 Analyse Trends

Index numbers make it easier to identify changes and trends in economic data.

03 · NOTATION

Basic Notation

These symbols are used throughout the index number calculations.

P₀ Price in the base period
P₁ Price in the current period
Q₀ Quantity in the base period
Q₁ Quantity in the current period

04 · METHOD

Laspeyres Price Index

What is it?

The Laspeyres price index uses the quantities from the base period as weights.

L = ΣP₁Q₀ / ΣP₀Q₀ × 100

Key idea

The quantities remain fixed at their base-period values while prices are compared between the two periods.

05 · METHOD

Paasche Price Index

What is it?

The Paasche price index uses the quantities from the current period as weights.

P = ΣP₁Q₁ / ΣP₀Q₁ × 100

Key idea

The current-period quantities are used to weight the price changes.

06 · METHOD

Fisher's Ideal Index

What is it?

Fisher's index is the geometric mean of the Laspeyres and Paasche price indices.

F = √(L × P)

Key idea

It combines the Laspeyres and Paasche indices into a single index.

07 · METHOD

Marshall–Edgeworth Index

What is it?

The Marshall–Edgeworth price index uses the combined quantities of the base and current periods as weights.

ME = ΣP₁(Q₀ + Q₁) / ΣP₀(Q₀ + Q₁) × 100

Key idea

Both base-period and current-period quantities are considered when weighting the prices.
